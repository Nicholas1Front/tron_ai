# Tron AI

Projeto pessoal para desenvolvimento de um agente de inteligência artificial modular, com suporte a diferentes interfaces, ferramentas, integrações e capacidades.

## Estrutura

- `agent-core/` — núcleo responsável pelo funcionamento do agente.
- `agent-desktop/` — aplicação e interface destinada ao computador.
- `agent-mobile/` — aplicação e interface destinada a dispositivos móveis.
- `agent-skills/` — capacidades, ferramentas e integrações que podem ser adicionadas ao agente.

## Status

Projeto em fase inicial de definição e arquitetura.

As decisões relacionadas à stack, segurança, autenticação, memória, comunicação entre componentes, ferramentas e integrações serão definidas durante o desenvolvimento.

## Objetivo

Construir uma plataforma pessoal de agente de IA que possa evoluir de forma modular, permitindo adicionar novas capacidades sem acoplar toda a aplicação a uma única interface ou serviço.
